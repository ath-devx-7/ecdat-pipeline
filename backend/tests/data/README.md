# Test data

Committed fixtures for the collector tests.

`weak-rsa1024-sha1.crt` is a copy of `demo/certs/weak.crt` — RSA-1024, SHA-1,
self-signed. The demo copy is generated by `demo/gen_certs.sh` and gitignored
along with the rest of `demo/certs/`, because that directory also holds private
keys. A certificate on its own carries no key material, so this one is committed
and the certificate tests run on a fresh clone with no OpenSSL and no Docker.

The tests prefer `demo/certs/weak.crt` when it exists, so they still assert
against the real demo target whenever the demo environment has been generated.

Regenerating it, if `gen_certs.sh` ever changes what it produces:

```sh
./demo/gen_certs.sh --force
cp demo/certs/weak.crt backend/tests/data/weak-rsa1024-sha1.crt
```

Modern `cryptography` refuses to *sign* with SHA-1, so this file cannot be built
from Python — which is exactly why it is committed rather than generated in a
fixture.
